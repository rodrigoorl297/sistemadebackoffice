SOU + BLU — como rodar o projeto
================================

REQUISITOS
----------
- Navegador moderno (Chrome, Edge, Firefox)
- Internet (Supabase em nuvem)
- Opcional: Node.js (servidor estático) ou PHP 8+ (API PIX)

1) MODO MAIS SIMPLES (recomendado)
----------------------------------
Na pasta do projeto:

  npm start

Abra no navegador: http://localhost:5500

Login: use e-mail ou matrícula cadastrados no Supabase (produção).
  O banco remoto já tem usuários reais — os logins "demo" (master@soublu.com)
  só existem se a tabela users estiver vazia na primeira carga.
  Teste de conexão: node test-supabase.js
  Documentação Supabase: SUPABASE.md

2) COM PHP (saques PIX locais)
------------------------------
  npm run start:php

Abra: http://localhost:8080

A API PIX fica em /api/pix_api.php (requer config.pix.local.php e certificados em certs/).

3) HOSPEDAGEM (Hostinger / Apache)
----------------------------------
Envie todo o conteúdo desta pasta para public_html.
O .htaccess já aponta index.html como página inicial.

4) PROBLEMAS COMUNS
-------------------
- Tela branca / "DB timeout": use servidor HTTP (npm start), não abra só o arquivo .html pelo Explorer.
- Erro Supabase: confira js/config.js (URL e chave anon) e RLS no painel Supabase.
- Logo: images/logo.png e images/logo.svg (substitua pelo logo oficial se quiser).
  Gere de novo o PNG: node scripts/gen-logo-png.js

5) TESTES
---------
  node test_proposal_save.js
